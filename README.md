# 🧩 Portfólio - Diogo Lima

## 🚀 Descrição do Projeto

Este é um portfólio pessoal desenvolvido com **React** e **Tailwind CSS**, criado com o objetivo de apresentar meus projetos, experiências e informações de contato de forma moderna, responsiva e interativa.

O site possui uma interface intuitiva, animações suaves e navegação fluida, utilizando rotas dinâmicas para exibir conteúdos como:

- **Resumo:** informações sobre minha trajetória profissional e acadêmica.
- **Projetos:** galeria interativa com busca dinâmica e rotas individuais de detalhes.
- **Contato:** formulário funcional com `alert()` e canais diretos (telefone e e-mail).

---


## 🧱 Estrutura do Projeto

O projeto segue uma arquitetura baseada em componentes reutilizáveis e organização modular:
```bash
src/
│
├── assets/ # Imagens e ilustrações
├── components/ # Componentes reutilizáveis (Navbar, Footer, Cards, SearchBar, etc)
├── data/ # Arquivos JSON com dados de projetos
├── pages/ # Páginas do site (Home, Resumo, Projetos, Contato)
├── routes/ # Configuração de rotas usando createBrowserRouter
├── App.jsx # Componente raiz do app
└── main.jsx # Ponto de entrada da aplicação
```

---

## 💻 Tecnologias Utilizadas

### 🧩 Front-end

- **React Router DOM** → controle de rotas e navegação entre páginas.
- **Tailwind CSS** → estilização responsiva e personalizável.
- **React Icons** → ícones vetoriais leves e modernos.
- **Vite** → ferramenta de build rápida e moderna para o ambiente React.

